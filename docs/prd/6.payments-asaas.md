# PRD — Epic 6: Pagamentos & Monetização (Asaas)

**Status:** Draft
**Owner:** Richard
**Criado:** 2026-05-11

## Motivação

PrintStudio é multi-tenant e cloud-only. Pra virar produto comercial
precisa de billing — Brasil-first (cartão, PIX, boleto) via **Asaas**.

Hoje qualquer usuário cria conta e usa de graça, sem limites. O objetivo
desta epic é entregar a base de monetização: planos, assinatura, controle
de acesso por plano, e o mínimo de painel de cobrança.

## Goals

1. Integração funcional com Asaas (sandbox + produção)
2. Modelo de planos (free + pago) com limites por tenant
3. Fluxo de assinatura na UI (escolher plano → pagar → ativar)
4. Webhook Asaas → ativar/desativar conta automaticamente
5. Painel admin (do owner do tenant) pra ver fatura/assinatura

## Decisões já tomadas

- **Gateway:** Asaas (BR-first, PIX nativo, boleto, cartão recorrente)
- **Modelo:** Assinatura mensal por org (não por usuário individual)
- **Free tier:** TBD — provavelmente 1 impressora, 7 dias retenção

## Non-Goals (V1)

- Stripe ou outros gateways internacionais
- Cobrança baseada em uso (g de filamento, horas de impressão)
  → Story separada futura (6.3)
- White-label de billing (cobrança em nome do tenant pro cliente dele)
- NF-e / faturamento eletrônico

## Stories

| ID | Título | Prioridade |
|----|--------|-----------|
| 6.1 | Asaas foundation (cliente HTTP, webhook handler, env) | P0 |
| 6.2 | Planos + limites (DB schema + enforcement no api) | P0 |
| 6.3 | UI de assinatura (escolher plano + checkout) | P0 |
| 6.4 | Painel de cobrança (fatura atual, próximas, cancelar) | P1 |
| 6.5 | Cobrança baseada em uso (futuro, V2) | P3 |

## Riscos

- Asaas API tem rate limits — precisa de retry/backoff
- Webhook duplicado / fora de ordem — idempotência crítica
- LGPD: dados de cobrança são pessoais, criptografar tokens da API key
  da Asaas (usar mesmo padrão dos `bambu_credentials`)

## Métricas de sucesso

- Onboarding de cliente novo: criação de conta → assinatura ativa em <5min
- 0 SQL manual pra alterar plano de tenant
- Webhook do Asaas processado em <2s p95
