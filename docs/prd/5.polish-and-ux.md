# PRD — Epic 5: Polish & UX

**Status:** Draft
**Owner:** Richard
**Criado:** 2026-05-11

## Motivação

Epic 4 entregou modo cloud-only funcional (api, web, worker no EasyPanel,
multi-tenant, .3mf cached por plate). O sistema funciona, mas a UX ainda
tem rough edges que impedem uso real por clientes além do dono.

Esta epic foca em **trazer o produto pra qualidade de demonstração**:
mobile responsive, kiosk com identidade visual forte, e ferramentas de
gestão de impressoras pelo usuário final (sem precisar mexer no banco).

## Goals

1. App funcional em mobile (visualização + interações primárias)
2. Kiosk com countdown/ETA visualmente impactantes
3. Usuário renomeia impressora pelo painel (preservando opção do nome
   original Bambu)
4. Usuário organiza ordem das impressoras no dash e no kiosk
5. Base pra webhooks (notificações HTTP de eventos)

## Non-Goals

- Refactor visual completo (Mission Control já está OK no desktop)
- Camera P2P/TUTK (Story 4.11 separada)
- White-label / customização de marca por tenant (futuro)

## Stories

| ID | Título | Prioridade |
|----|--------|-----------|
| 5.1 | Mobile responsiveness | P0 |
| 5.2 | Kiosk: tempo restante visual | P1 |
| 5.3 | Renomear impressora (nome custom + fallback original) | P1 |
| 5.4 | Reordenar impressoras (dash + kiosk) | P2 |
| 5.5 | Webhooks (notificações HTTP) | P3 (futuro) |

## Métricas de sucesso

- App utilizável em iPhone SE (375px) sem scroll horizontal
- Kiosk com ETA visível a 3m de distância
- 0 SQL manual pra renomear ou reordenar impressoras
