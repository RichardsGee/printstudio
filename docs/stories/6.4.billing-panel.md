# Story 6.4 — Painel de Cobrança

**Status:** Draft
**Epic:** 6 — Pagamentos & Monetização
**Tipo:** Frontend
**Estimativa:** 1-2 dias
**Depende de:** Story 6.3

## Contexto

Owner do tenant precisa ver histórico de cobrança, baixar comprovantes
de pagamento e gerenciar dados de cobrança.

## Acceptance Criteria

1. Lista de faturas (últimos 12 meses) com:
   - Data, valor, status (paid/pending/overdue), método (PIX/cartão/boleto)
   - Link pra ver fatura no Asaas (URL hospedada)
2. Próxima fatura: data prevista + valor
3. Botão "Atualizar forma de pagamento" → redireciona pro Asaas
4. Dados do customer (nome, email, CPF/CNPJ) editáveis com confirmação
5. Histórico paginado (10 por página)

## Non-Goals

- Geração de NF-e (futuro)
- Reembolsos pela UI (manual via Asaas painel)

## Arquivos prováveis

- `apps/web/src/app/(app)/settings/billing/history/page.tsx`
- `apps/api/src/routes/billing.ts` — GET /api/billing/invoices

## Dev notes

- Asaas API: `GET /v3/payments?customer={id}&offset=...`
- Cache de 5 min em invoices pra reduzir chamadas
