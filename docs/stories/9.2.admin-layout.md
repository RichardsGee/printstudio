### Decisões

- **Active state com `startsWith(`${href}/`)`:** cobre sub-rotas
  futuras (ex: `/admin/waitlist/123` mantém "Waitlist" highlighted).
  Empty `pathname === href` cobre exato; `startsWith` cobre nested.
- **Badge story por nav item (9.3, 9.5, etc):** dual-purpose UI —
  identifica quais sections estão prontas vs em-breve, e como visual
  de roadmap pra Richard navegar o desenvolvimento.
- **Drawer Radix em vez de menu accordion sticky:** padrão já
  estabelecido pelo Story 5.1 (mobile responsive). Familiar pra
  o user.
- **Header sticky com backdrop-blur:** quando user scrollar uma
  lista longa de leads (Story 9.3), nav fica acessível sem ter que
  rolar de volta. Padrão consistente com `apps/marketing` (Story 7.2).
- **`max-w-7xl` no admin vs `max-w-6xl` do app normal:** admin
  precisa de mais largura horizontal pra tabelas densas (waitlist,
  users, etc).
- **Substitui placeholder Story 9.1 sem manter SectionCards:** o
  mapa de stories agora vive na sidebar (visível em todas as páginas
  admin). Redirect direto pra `/admin/waitlist` é o fluxo certo —
  user nunca cai em página intermediária inútil.
