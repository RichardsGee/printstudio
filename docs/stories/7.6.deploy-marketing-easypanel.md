## Acceptance Criteria

1. **Domínio registrado:** `guiaprint3d.com` ativo no Registro.br (ou
   provider equivalente). **Pré-requisito externo** — Richard registra
2. EasyPanel app criado pra `apps/marketing`
3. Dockerfile pra build static + serve (nginx ou Caddy)
4. `pnpm build` gera `out/` que é servido por nginx/Caddy
5. DNS A record `guiaprint3d.com` aponta pro IP do EasyPanel
6. DNS A record `www.guiaprint3d.com` redirect 301 pra `guiaprint3d.com`
7. **SSL:** HTTPS automático via Let's Encrypt (EasyPanel suporta nativo)
8. App autenticado migra pra `app.guiaprint3d.com` (DNS update)
9. Variáveis de ambiente configuradas:
   - `NEXT_PUBLIC_API_URL` = endpoint público de `/api/waitlist`
10. Smoke test pós-deploy: GET `https://guiaprint3d.com/` retorna 200 +
    HTML válido
11. Form submit do site público funciona end-to-end (testa em prod, não
    só local)

## Dev notes

- **Build static:** `next build` com `output: 'export'` gera `out/`,
  nginx serve `out/index.html` com tryFiles fallback
- **Headers de segurança:** nginx config inclui CSP, X-Frame-Options,
  X-Content-Type-Options, Referrer-Policy
- **Caching:** assets estáticos com `Cache-Control: max-age=31536000,
  immutable`. HTML com `Cache-Control: no-cache` pra deploys rápidos
- **API CORS:** garantir que `apps/api` tem `guiaprint3d.com` no
  whitelist CORS (story 7.3)
- **DNS propagation:** pode levar até 24h. Planejar deploy fora do
  horário de pico
- **Subdomain migration:** se hoje o app está em
  `criartificial-printstudio.z9ivjr.easypanel.host`, mover pra
  `app.guiaprint3d.com` em paralelo (ou subpath, decidir com Architect)
