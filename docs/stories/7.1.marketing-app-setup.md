## Contexto

PrintStudio precisa de presença pública em `guiaprint3d.com` separada do
app autenticado (`app.guiaprint3d.com`). Decisão fechada no PRD 7:
**Next.js separado** em `apps/marketing/`, hospedado no EasyPanel,
reaproveitando Tailwind + tokens Mission Control do app existente.

Esta story é o **scaffolding** — não tem UI ainda, só estrutura pra
próximas stories construírem em cima.

## Acceptance Criteria

1. `apps/marketing/` criado como workspace package (`@printstudio/marketing`)
2. `pnpm dev` na raiz inclui `apps/marketing` rodando em porta separada (3002)
3. `pnpm build` empacota static export (`output: 'export'` no next.config)
4. Tailwind config herdado/copy do `apps/web` (tokens Mission Control disponíveis)
5. `globals.css` + `mission-control.css` importados (visualização do tema OK)
6. Página inicial placeholder com `<PageHeader>` (importado do app ou copiado) renderiza com tema Mission Control aplicado
7. TypeScript + ESLint configs alinhados com `apps/web` (zero erros novos)
8. Adicionado em `pnpm-workspace.yaml`
9. `apps/marketing/package.json` define scripts `dev`, `build`, `start`, `lint`, `typecheck`

## Dev notes

- **Output mode:** `output: 'export'` (Next.js static export). Sem SSR
  por padrão — landing é puramente static. Permite hospedar em
  Cloudflare Pages no futuro sem refator
- **Compartilhamento de tema:** V1 = copy de `mission-control.css`.
  V1.1 = extrair pra `packages/ui` (story futura)
- **Shadcn components:** copia só os essenciais (Button, Card) pra
  evitar bloat. Não importa de `@printstudio/web` (acoplamento)
- **Port:** dev em 3002 (web está em 3000/3001, api em 3000/4000)
- **PWA:** desabilitar `next-pwa` no marketing (não faz sentido)
