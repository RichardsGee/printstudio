# Story 5.1 — Mobile Responsiveness

**Status:** Draft
**Epic:** 5 — Polish & UX
**Tipo:** Frontend
**Estimativa:** 2-3 dias

## Contexto

App foi construído desktop-first com layout Mission Control denso. Em
telas <768px o layout quebra: cards sobrepõem, sidebar empurra o conteúdo,
gráficos vazam horizontal.

Usuários reais vão acessar pelo celular pra dar uma olhada rápida no
status. O fluxo principal mobile é **leitura**, não gestão profunda.

## Acceptance Criteria

1. Layout funcional em 375px (iPhone SE) sem scroll horizontal
2. Sidebar vira drawer/sheet em <768px
3. Dashboard de impressoras: grid 1 coluna em mobile, 2 em tablet
4. Página de detalhe da impressora: cards empilham verticalmente
5. Kiosk: já é fullscreen, validar que escala bem em portrait/landscape
6. Tipografia: hierarquia legível sem zoom (mínimo 14px corpo)
7. Touch targets >=44px (botões, links de menu)
8. Testes manuais em Chrome DevTools devices: iPhone SE, iPhone 14, iPad

## Non-Goals

- Reescrever componentes 3D pra performance mobile (manter como está)
- App nativo (PWA é suficiente)
- Gestão complexa (criar usuário, vincular conta Bambu) tem que funcionar
  mas pode não ser bonito
