# Story 8.5 — Onboarding wizard step 3 — auto-add printers detectadas (skippable)

**Status:** Draft
**Epic:** 8 — Customer Onboarding
**Tipo:** Frontend + Backend
**Estimativa:** 1.5d
**Depends on:** 8.4 (Bambu vinculado), 8.6 (free tier enforce max 1)

## Contexto

Último step do wizard. Após vincular Bambu Cloud, listar impressoras
detectadas e permitir user selecionar **qual cadastrar**. Free tier
permite só **1 impressora** — selection enforced.

Resolve dor real: hoje precisa POST manual via API pra cadastrar
cada impressora.

## Acceptance Criteria

1. Página `/onboarding/add-printers` em `apps/web/src/app/onboarding/add-printers/page.tsx`
2. Server component:
   - Verifica `onboarding_step == 'add_printers'`
   - Busca impressoras Bambu detectadas via API existente
     (`/api/bambu/devices` ou similar — verificar nome do endpoint)
   - Renderiza lista
3. Lista de impressoras:
   - Pra cada device: card com imagem placeholder + nome editável + model + serial
   - **Free tier:** radio button (não checkbox) — só 1 selecionável
   - Pre-selected = primeira impressora
   - Nome editável inline (default = nome Bambu, user pode customizar)
4. Submit `[Adicionar impressora]`:
   - Server action `addPrintersFromBambu(selected: { serial, name }[])`
   - INSERT na tabela `printers` com `organization_id` do user
   - Atualiza `org.onboarding_step = 'done'`
   - Set `org.onboarding_completed_at = now()`
   - Redirect `/kiosk`
5. **Botão skip:** `[Pular — adicionar depois]`
   - Mesma lógica que skip Bambu (story 8.4): step = 'skipped'
   - Redirect `/dashboard` com banner (story 8.7)
6. Empty state: se Bambu vinculou mas não retornou nenhuma device:
   - Mensagem "Nenhuma impressora encontrada na sua conta Bambu Cloud"
   - CTA `[Voltar pra Bambu Connect]` ou `[Pular]`
7. Layout: PageHeader `id="ONBOARDING-3/3"`, título "Quais impressoras monitorar?"
8. Progress: `[✓] Perfil → [✓] Bambu → [●] Impressoras`
