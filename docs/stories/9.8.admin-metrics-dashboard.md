# Story 9.8 — Dashboard métricas (DAU, MAU, conversion, MRR, churn)

**Status:** Draft
**Epic:** 9 — Internal Admin Panel
**Tipo:** Frontend + Backend
**Estimativa:** 2d
**Depends on:** 9.1-9.7 (dados existem)

## Contexto

Visão única das métricas-chave do negócio. Permite Richard tomar
decisões data-driven sem montar dashboards externos.

## Acceptance Criteria

1. Página `/admin/metrics` com:
2. **Cards top (KPIs):**
   - DAU (active 24h)
   - WAU (active 7d)
   - MAU (active 30d)
   - Total signups (+ delta 7d/30d)
   - MRR (Monthly Recurring Revenue)
   - Churn rate 30d
   - Conversion waitlist → signup
   - Conversion free → paid (em 30d)
3. **Gráficos** (recharts já no projeto):
   - Signups por dia (line chart últimos 90d)
   - MRR por mês (bar chart últimos 12m)
   - Funil de onboarding (waitlist → signup → bambu_connected →
     first_print → paid) — usa `onboarding_events` da story 8.10
   - Distribuição planos (pie chart)
   - Distribuição região (mapa BR ou bar chart UF)
4. **Filtros:**
   - Range de data (default últimos 30d)
   - Plano (filtra KPIs e gráficos)
   - Região (filtra)
5. **Refresh:** botão manual + auto a cada 60s (configurável)
6. **Export:** botão exportar métricas como JSON ou CSV (depende 9.10)

## Dev notes

- **Performance:** queries agregadas podem ser pesadas. Cache em
  memória 5min OU pre-compute em job periódico (cron 5min)
- **DAU/MAU:** baseado em `last_activity_at` denormalizado (story 9.5)
- **MRR:** `SUM(amount_cents / 100)` ajustado por cycle (anual / 12).
  Status = 'active' apenas
- **Funil:** join `waitlist` + `onboarding_events` + `subscriptions`
- **Recharts:** já no projeto. Reusar styles Mission Control
- **V1 simplicidade:** sem real-time, sem WebSocket. Pull on demand
