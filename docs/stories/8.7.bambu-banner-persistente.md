# Story 8.7 — Banner persistente "vincule sua Bambu" quando skip

**Status:** Ready
**Epic:** 8 — Customer Onboarding
**Tipo:** Frontend
**Estimativa:** 0.5d
**Depends on:** 8.4 (skip flow existe)

## Contexto

Decisão fechada PRD 8: skip Bambu Connect permitido **com banner
persistente** lembrando user de vincular. Reduz risco de conta zumbi.

Banner aparece em todas as páginas do `(app)` quando user pulou ou
não completou Bambu Connect.

## Acceptance Criteria

1. Componente `<NoBambuBanner>` em `apps/web/src/components/`:
   - Renderiza só se `org.onboarding_step IN ('skipped', 'bambu_connect')`
   - Cor warning amarelo (`bg-warning/15 border-warning/40`)
   - Texto: "⚠ Sua conta não tem impressora vinculada"
   - CTA: `[Conectar agora →]` linka pra `/settings/bambu-connect`
   - Dismissível? **NÃO V1** — persistente forçado (UX deliberadamente
     persistente até user resolver)
2. Banner aparece **em todas as rotas** do `(app)/layout.tsx`:
   - `/dashboard`
   - `/kiosk`
   - `/history`
   - `/events`
   - `/settings/*`
   - `/printers/[id]`
3. **Não aparece** se:
   - User não logado
   - `org.onboarding_step == 'done'`
   - User tem pelo menos 1 impressora ativa (`printers` count > 0)
4. Visual Mission Control consistente: `data-mc-banner`, font mono,
   uppercase tracking-wider
5. Após user vincular Bambu E adicionar 1+ impressora, banner some
   automaticamente (server component re-render)

## Arquivos prováveis

- `apps/web/src/components/no-bambu-banner.tsx` (NOVO)
- `apps/web/src/app/(app)/layout.tsx` (atualizar — renderizar banner)

## Dev notes

- **Server-side check:** banner é server component, busca org + count
  printers em 1 query. Renderiza ou null
- **Performance:** query indexed por organization_id. Pra cache, depende
  se usa React cache ou middleware
- **UX deliberadamente persistente:** decisão de produto pra forçar ação.
  V1.1 pode adicionar opção "Lembrar depois" com cooldown
- **Layout integration:** banner posiciona **acima** do `<AppHeader>` ou
  **abaixo**? Recomendo abaixo do header, ocupando full-width
