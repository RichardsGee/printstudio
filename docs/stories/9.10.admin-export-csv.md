# Story 9.10 — Export CSV (waitlist, users, subscriptions)

**Status:** Draft
**Epic:** 9 — Internal Admin Panel
**Tipo:** Backend + Frontend
**Estimativa:** 0.5d
**Depends on:** 9.3, 9.5, 9.7 (entidades existem)

## Contexto

Permite Richard exportar dados pra trabalhar offline (planilha,
análise externa) e compliance LGPD (portabilidade de dados).

## Acceptance Criteria

1. Botão `[📥 Exportar CSV]` em cada lista admin:
   - `/admin/waitlist`
   - `/admin/orgs`
   - `/admin/subscriptions`
2. Endpoint `GET /api/admin/export/{entity}.csv`:
   - `entity` ∈ {waitlist, orgs, subscriptions, audit}
   - Aplica filtros vigentes (passados via query params)
   - **Streams** CSV pra evitar memória (pra waitlist grande)
   - Header `Content-Disposition: attachment; filename="{entity}-{date}.csv"`
   - MIME: `text/csv; charset=utf-8`
3. **CSV format:**
   - Linha 1: headers em português
   - Encode UTF-8 BOM (Excel BR abre corretamente)
   - Campos com vírgula/aspas escapados
   - Dates ISO 8601
4. **Audit log entry** quando export executado:
   - `admin.export_executed` com `{entity, filter_summary, row_count}`
5. **PII sanitization:**
   - Telefone parcial (`+55 11 9XXXX-1234` mascarado)?
   - **DECISÃO V1:** export retorna tudo (admin tem acesso total),
     mas log captura
6. Performance: streaming pra >10k rows sem time out

## Dev notes

- **Streaming:** Postgres cursor + write chunked. Drizzle suporta
  via raw queries
- **CSV escape:** field com `,` ou `"` ou `\n` → wrap com `"..."` +
  duplicate quotes inside
- **Excel BR encoding:** UTF-8 BOM no início (`﻿`)
- **Filename:** `waitlist-2026-05-13.csv`
- **PII:** decisão produto = export inclui PII porque é uso admin
  legítimo. Audit log captura quem exportou + quando
- **Async grande:** se entidade tem >50k rows, considerar gerar
  background + emitir email com link (V2)
