# Story 7.4 — Política de privacidade + termo de uso (template LGPD)

**Status:** Draft
**Epic:** 7 — Landing & Waitlist
**Tipo:** Docs / Frontend
**Estimativa:** 0.5d
**Depends on:** 7.1 (setup marketing)

## Contexto

Pra capturar dados pessoais no form de waitlist (email, nome, telefone,
endereço IP) PrintStudio precisa cumprir LGPD mínimo: política de
privacidade declarando uso + termo de uso + opt-in explícito.

Decisão fechada PRD 7: **template open-source LGPD adaptado** (não
escrever do zero, não advogado V1).

## Acceptance Criteria

1. Página `/politica-de-privacidade` em `apps/marketing` renderizando
   markdown estático
2. Página `/termos-de-uso` em `apps/marketing` renderizando markdown
   estático
3. Conteúdo adaptado pra PrintStudio (não genérico):
   - Política: dados coletados (email, nome, telefone, IP, UTM),
     finalidade (contato comercial), compartilhamento (não vende),
     retenção (90 dias se não converter), direitos LGPD do titular
     (acesso, correção, exclusão), contato DPO (Richard)
   - Termos: definições, aceitação, uso aceitável, propriedade
     intelectual, limitação de responsabilidade, foro (cidade da
     sede), alterações nos termos
4. Links no footer da landing apontam pra essas páginas
5. Link na checkbox do form de waitlist (story 7.2): "Aceito os
   [termos](#) e [política de privacidade](#)"
6. Páginas com `text-body` legível, design Mission Control consistente
7. SEO: meta description "Política de Privacidade do PrintStudio" + canonical URLs
