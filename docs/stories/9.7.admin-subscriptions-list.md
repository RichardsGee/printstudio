# Story 9.7 — Lista subscriptions com filtros (status, valor, próxima cobrança)

**Status:** Ready
**Epic:** 9 — Internal Admin Panel
**Tipo:** Frontend + Backend
**Estimativa:** 1d
**Depends on:** 9.2 (admin layout), 6.2 (subscriptions schema do Epic 6)

## Contexto

View admin de todas as assinaturas ativas/canceladas/pendentes do
sistema. Ações operacionais: forçar cobrança, refund manual, marcar
pago.

V1 pode renderizar com dados vazios (Epic 6 ainda não implementado),
mas schema + UI prontos pra quando Epic 6 chegar.

## Acceptance Criteria

1. Página `/admin/subscriptions` com tabela:
   - Colunas: org, plano, cycle (mensal/anual), status (badge),
     valor (R$), próxima cobrança, total pago, refund eligible até
2. **Filtros:**
   - Status (active/past_due/cancelled/refunded multi)
   - Plano (multi)
   - Cycle (mensal/anual)
   - Range valor mensal
3. **Métricas top:**
   - MRR total
   - Anual MRR (anual / 12)
   - Churn rate 30d
   - Pending payments count
4. **Ações por linha:**
   - Forçar cobrança (chama Asaas API — V1.1 quando Epic 6 entregar)
   - Marcar pago manualmente (admin override, gera audit)
   - Cancelar (com confirmação)
   - Refund manual (com justificativa obrigatória)
5. **Click na linha** → drawer ou modal com detalhes da subscription
   + histórico de invoices
6. **Sync com Asaas** (botão "Sincronizar status"): força refresh do
   status via API Asaas (V1.1)

## Dev notes

- **Dependência Epic 6:** UI pronta funciona vazia. Quando Epic 6
  entregar, popula
- **MRR cálculo:** `SUM(amount_cents / 100) WHERE status='active'`
  ajustado por cycle (anual / 12)
- **Asaas integration:** server actions chamam Asaas via service. V1.1
  quando 6.1 entregar (Asaas SDK)
- **Audit:** toda ação destrutiva (refund, force cobrança, marcar pago
  manual) gera audit log
- **Pending payments:** filtrar `status IN ('past_due', 'pending_payment')`

## CodeRabbit Integration

- Foco: financial accuracy (R$ math, cycle conversion), audit, security
  (manual refund é dinheiro real)
- Severity: CRITICAL = block (financial bugs)
