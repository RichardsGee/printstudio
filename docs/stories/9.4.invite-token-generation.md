# Story 9.4 — Gerar token de convite (libera lead pra signup)

**Status:** Ready
**Epic:** 9 — Internal Admin Panel
**Tipo:** Backend + Frontend
**Estimativa:** 0.5d
**Depends on:** 9.3 (admin waitlist UI), 8.2 (invite_tokens table)

## Contexto

Loop crítico: lead na waitlist → Richard clica "Liberar acesso" →
sistema gera token → Richard copia URL e envia manual (WhatsApp/email)
→ lead acessa /signup?invite={token} → conta criada com pre-fill.

## Acceptance Criteria

1. Botão `[🔗 Gerar link de convite]` em cada linha da waitlist
   (story 9.3) ou no detail drawer
2. Click → server action `generateInviteToken(waitlistId)`:
   - Gera token random URL-safe (`nanoid(32)` ou `ulid()`)
   - INSERT em `invite_tokens` (token, waitlist_id, expires_at = now() + 30 days)
   - Atualiza `waitlist.status = 'invited'`
   - Retorna URL completa: `https://app.guiaprint3d.com/signup?invite={token}`
3. UI mostra modal/toast com:
   - URL completa
   - Botão `[📋 Copiar pro clipboard]`
   - "Válido por 30 dias"
4. Audit log entry: `admin.invite_generated` com waitlist_id no payload
5. Re-gerar token: se waitlist já tem token ativo, invalida o antigo
   (`used_at = now()` ou similar marker) e cria novo
6. Listagem dos tokens ativos no detail da waitlist (opcional V1):
   - Histórico de tokens gerados + status (used/expired/active)

## Dev notes

- **Token format:** `nanoid(32)` produz strings URL-safe sem ambiguity
  characters (0/O, 1/l). 32 chars = ~190 bits entropia
- **30 days expiry:** decisão V1. Pode ser configurável V2
- **Atomic regenerate:** transação garante: invalida antigo + cria novo
  em 1 step
- **URL pattern:** `app.guiaprint3d.com/signup?invite={token}` —
  preserva domain pattern decidido no Epic 7
- **Copy to clipboard:** `navigator.clipboard.writeText()` com fallback
  manual select
- **Histórico V1.1:** mostrar tokens gerados anteriores. V1 só novo.

## CodeRabbit Integration

- Foco: token entropy (não usar Math.random), atomic regenerate (race
  condition), audit completeness
- Severity: CRITICAL = block (low entropy token)
