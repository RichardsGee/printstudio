# Story 4.2 — Schema Multi-tenant

**Status:** InProgress
**Epic:** 4 — Cloud-only mode
**Tipo:** Foundation / Database
**Estimativa:** 3 dias

## Contexto

POC 4.1 validou que dá pra conectar 100% via Bambu Cloud (login por código,
MQTT cloud, telemetria ao vivo). Antes de construir a UI de conexão (4.4)
e o worker cloud (4.5), o DB precisa suportar **múltiplas organizações**
— cada uma com suas próprias impressoras, jobs, eventos e credenciais Bambu.

Hoje todas as tabelas são single-tenant implícito (um deployment = um
"dono"). Esta story adiciona `organizations` + membership e propaga
`organization_id` pras tabelas de dados.

## Acceptance Criteria

1. Tabela `organizations` criada (id, name, createdAt, updatedAt)
2. Tabela `organization_members` criada (org, user, role unique-by-pair)
3. Enum `organization_member_role` (`owner` | `admin` | `member`)
4. Coluna `organization_id` NOT NULL FK adicionada em:
   - `printers`
   - `events`
   - `print_jobs`
   - `temperature_samples`
5. Migration backfill: cria org "Default" e atribui todos os dados
   existentes a ela; todos os `users` viram `owner` dessa org
6. `pnpm --filter @printstudio/db typecheck` passa
7. Migration aplicada com sucesso no Postgres do EasyPanel (sem perder dados)
8. Não quebra fluxos existentes (login, dashboard, bridge)

## Non-Goals (próximas stories)

- ❌ UI pra criar/trocar orgs (Story 4.4)
- ❌ Tabela `bambu_credentials` (Story 4.3)
- ❌ RLS no Postgres (Story 4.5+ se necessário)
- ❌ Filtrar queries por `organization_id` em runtime (faremos junto com 4.5)

A intenção desta story é só **estrutura**. Code de runtime continua usando
queries globais até as próximas stories.

## Default org / migration determinism

A migration usa um UUID fixo conhecido pra org "Default":
`00000000-0000-0000-0000-000000000001`

Justificativa: permite que migrations futuras referenciem essa org sem
precisar de variável de ambiente / state externo. Em produção real, depois
do flow de "criar nova org" estar pronto (Story 4.4), o operador pode
renomear a org default pra algo significativo (ex: "Criartificial").
