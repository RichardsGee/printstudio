# Story 9.1 — Schema `is_super_admin` flag + middleware de acesso

**Status:** Draft
**Epic:** 9 — Internal Admin Panel
**Tipo:** Backend + DB
**Estimativa:** 1d
**Depends on:** — (foundation)

## Contexto

Foundation do Admin Panel. Adicionar **flag boolean** `is_super_admin`
em `users` + middleware server-side que protege todas as rotas
`/admin/*`. Decisão fechada PRD 9: **single super_admin V1** (só
Richard).

Segurança crítica: flag **nunca** pode ser editável via API normal.

## Acceptance Criteria

1. Migration aplica:
   ```sql
   ALTER TABLE users ADD COLUMN is_super_admin boolean DEFAULT false NOT NULL;
   CREATE INDEX users_super_admin_idx ON users (is_super_admin) WHERE is_super_admin = true;
   ```
2. Middleware Next.js (`apps/web/src/middleware.ts` ou layout server
   component) em `(admin)/layout.tsx`:
   - Lê `session` via NextAuth
   - Busca `user.is_super_admin` no DB
   - Se NÃO super_admin → `notFound()` (404, não 403 — não revela
     existência da rota)
   - Se OK, passa pra page
3. `PATCH /api/users/:id` (endpoint existente ou novo) **REJEITA**
   qualquer payload contendo `is_super_admin`:
   - Server-side strip do campo
   - Logs warning "attempt to escalate privilege"
4. Helper `requireSuperAdmin()` em `apps/web/src/lib/auth.ts`:
   - Verifica session + flag
   - Lança erro com redirect se não passar
   - Usado em todas rotas `/admin/*`
5. Seeder ou SQL manual pra promover Richard:
   - `UPDATE users SET is_super_admin = true WHERE email = '{richard-email}';`
   - Documentar em `docs/architecture/admin-setup.md`

## Dev notes

- **Single source of truth:** `users.is_super_admin` é a flag. Sem RBAC
  granular V1
- **404 vs 403:** retornar 404 esconde existência da rota (security
  through obscurity reforço, não primário)
- **Escalation prevention:** validar Zod schema input PATCH user — strip
  `is_super_admin` antes de pegar resto. Test crítico
- **Session check:** middleware verifica em CADA request /admin/*
  (não confia em cookie sozinho)
- **Route group `(admin)`:** isolated layout pra não vazar dependências
  pro `(app)` normal
