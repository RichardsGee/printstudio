# Story 8.4 — Onboarding wizard step 2 — vincular Bambu (com opção skip)

**Status:** Draft
**Epic:** 8 — Customer Onboarding
**Tipo:** Frontend
**Estimativa:** 0.5d
**Depends on:** 8.3 (step profile completo)

## Contexto

Segundo step do wizard. Reusa componente existente `/settings/bambu-connect`
(já funcional desde Epic 4). User pode **pular** (decisão PRD 8) e
vincular depois — banner persistente lembra (story 8.7).

## Acceptance Criteria

1. Página `/onboarding/bambu-connect` em `apps/web/src/app/onboarding/bambu-connect/page.tsx`
2. Server component verifica `onboarding_step`:
   - Se `!= 'bambu_connect'` → redirect step certo
3. **Reusa componente** `BambuConnectClient` de
   `apps/web/src/app/(app)/settings/bambu-connect/` (já existe, funcional)
4. Após sucesso na vinculação (callback do componente):
   - Server action `advanceOnboardingStep` atualiza `org.onboarding_step = 'add_printers'`
   - Redirect `/onboarding/add-printers`
5. **Botão skip** no canto:
   - `[Pular por enquanto]` (variant outline, smaller que primary)
   - Click → server action `skipBambuConnect` atualiza:
     - `org.onboarding_step = 'skipped'`
     - `org.onboarding_completed_at = now()`
   - Redirect `/dashboard` (não `/kiosk` — sem impressoras pra mostrar)
6. Layout: PageHeader `id="ONBOARDING-2/3"`, título "Conecte sua Bambu Cloud"
7. Progress indicator: `[✓] Perfil → [●] Bambu → [○] Impressoras`
8. Mensagem informativa: "Vamos buscar suas impressoras automaticamente
   da sua conta Bambu Cloud."

## Dev notes

- **Reuse strategy:** componente `BambuConnectClient` já tem flow
  email/code/devices/success. Wrap ele com onSuccess callback que
  chama server action de advance
- **Skip não é destrutivo:** user pode voltar pra `/settings/bambu-connect`
  depois e vincular. `onboarding_step = 'skipped'` mantém histórico
- **Bambu rate limit:** com volume 50-200 signups/dia, pode bater
  rate limit Bambu Cloud durante onboarding. Mitigação: cache
  access_token por org (já implementado) + retry exponencial
  (validar com Architect)
- **Skip confirma:** modal pequeno "Tem certeza? Você pode vincular
  depois em Configurações" pra reduzir skip acidental

## CodeRabbit Integration

- Foco: state machine integrity (não pular pra add-printers sem

- Severity: HIGH (UX breaks)
