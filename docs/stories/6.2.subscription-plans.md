# Story 6.2 — Schema subscriptions + plan_limits + tax_id/billing_address

**Status:** Draft
**Epic:** 6 — Pagamentos & Monetização
**Tipo:** Backend + DB
**Estimativa:** 1d
**Depends on:** 8.2 (organizations.plan existe)

## Contexto

Schema completo do billing definido no PRD 6: tabelas `subscriptions`,
`asaas_webhook_events`, `subscription_invoices`, mais campos fiscais
em `organizations`.

Tiers já implementados no Epic 8 (`lib/plan-limits.ts`). Esta story
foca em **billing-specific schema** pra suportar Asaas + NF-e.

## Acceptance Criteria

1. Migration drizzle aplica:
   - Type enum `subscription_status` (active/past_due/cancelled/expired/pending_payment/refunded)
   - Type enum `billing_cycle` (monthly/yearly)
   - Tabela `subscriptions` (id, org_id UNIQUE, asaas_customer_id,
     asaas_subscription_id UNIQUE, plan, cycle, status,
     current_period_start, current_period_end, cancel_at_period_end,
     first_paid_at, refund_eligible_until, created_at, updated_at)
   - Tabela `asaas_webhook_events` (id, event_id UNIQUE, event_type,
     payload jsonb, processed_at, processing_error, created_at)
   - Tabela `subscription_invoices` (id, subscription_id FK, asaas_payment_id UNIQUE,
     amount_cents, status, paid_at, due_date, refunded_at, refund_reason,
     nfe_* fields pra V1.1, created_at)
   - Indexes: `asaas_events_processed_idx`, `subscription_invoices_sub_idx`
2. `organizations` ganha campos fiscais (capturados no upgrade — Story 6.3):
   - `tax_id_type` text ('CPF' | 'CNPJ')
   - `tax_id` text
   - `billing_address` jsonb ({street, number, complement, district, city, state, zip})
3. Tiers configuráveis em código:
   - Ver `lib/plan-limits.ts` (Epic 8 story 8.6) — já implementado
   - Esta story alinha **billing cycle pricing** (Pro mensal R$49 / anual R$470)
4. Constants em `apps/web/src/lib/plan-pricing.ts` ou `packages/shared`:
   ```ts
   export const PLAN_PRICING = {
     free: { monthly: 0, yearly: 0 },
     pro: { monthly: 4900, yearly: 47040 }, // cents, anual = 49 * 12 * 0.8
     business: { monthly: 19900, yearly: 191040 },
   };
   ```

## Dev notes

- **Anual 20% desc:** `monthly * 12 * 0.8` = `monthly * 9.6`.
  Pro = R$49 * 9.6 = R$470.40 (~R$470 arredondado)
- **Cents storage:** preço em centavos (int) evita floating-point
- **`subscriptions.org_id UNIQUE`:** 1 subscription por org (V1).
  Múltiplas subs V2
- **NFs fields `nfe_*`:** preenchidas só V1.1 (story 6.9). Schema
  preparado mas inativo V1
- **Migration order:** depende de Epic 8 8.2 (organizations.plan
  existe) — verificar ordem aplicação
